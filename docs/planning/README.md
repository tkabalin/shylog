# Planning

The documents Shylog was planned and built from. They record what was intended at the start and the decisions taken along the way, and many details changed as the app was built and tried on the phone. The app as it stands is described in the topic docs one level up and in the [README](../../README.md), and where anything here disagrees with the code, the code is what runs.

- [SPEC.md](SPEC.md) is the full specification: every rule, field and screen. It was updated as features landed and checked against the code wherever the topic docs touch it, but it has not been audited line by line, so some detail may have drifted.
- [PLAN.md](PLAN.md) is the build plan: the milestones in the order they were built, the decisions taken along the way (D1 onwards), notes handed from one milestone to the next, and the next steps. A milestone's text is the plan as it stood when it was written, and later decisions often changed it.
- [design/](design/) holds the hi-fi wireframes drawn before the build began. They were each screen's starting point, and many screens have moved on since: through review on the phone, the desktop layout no board draws, and features the boards never had. [NOTES.md](design/NOTES.md) lists the main departures, not every one.
