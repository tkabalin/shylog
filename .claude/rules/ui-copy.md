# UI copy

- No muted footers, hints or notes that tell the diver what the screen already shows or what the gestures obviously do: how to swipe or pinch, which item shows first, crop advice, "add more if…". A footer that says something the diver couldn't otherwise know stays, such as the certifications list's "Stored offline." (nothing on screen says the cards open without signal). Its "Hold and drag to reorder." went once each row had a grip, which shows it moves.
- The boards' helper copy is not binding. `CertsHifi` carried a hint under almost every element and the owner cut them one by one in PR #26. Leave a board's hint out unless it passes the rule above, and say which ones you left out.
- When asked to drop or change a piece of copy, find every variant of it in the same pass (phone and desktop wording, New and Edit, one and many) and handle them all, then list them in the report.
- Name the dive computer only when the app knows it, read from the watch or from an import's model, as on a detected computer's card. Otherwise say "your dive computer" and never assume a model: "From the D4i" on a computer value was wrong because the value doesn't say which computer it came from.
