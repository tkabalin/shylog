# mobile-native

- Use the mobile-native skill whenever you build or change a screen, sheet, form, navigation, or the app shell (`index.html`, `index.css`, the PWA manifest). Shylog is used on a phone, so every web change counts as mobile work.
- Its rules sit alongside the UI conventions in `CLAUDE.md`, which already set 16px input text and the `inputmode` values.
- Only a real phone can confirm these fixes, so list the ones that need one in your report instead of calling them done.
